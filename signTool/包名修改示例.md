# 包名修改工具使用示例

## 📋 功能说明

`change_package.sh` 工具可以帮您：
- 修改Android应用的包名
- 更新签名配置
- 可选更新微信AppID
- 自动备份原文件
- 支持一键还原

## 🚀 使用方法

### 1. 基本用法（不修改微信AppID）
```bash
cd signTool
./change_package.sh com.newcompany.newapp myapp.keystore
```

### 2. 完整用法（包含微信AppID）
```bash
cd signTool
./change_package.sh com.newcompany.newapp myapp.keystore wx1234567890abcdef
```

### 3. 还原包名
```bash
cd signTool
./change_package.sh restore
```

## 📝 参数说明

| 参数 | 必需 | 说明 | 示例 |
|------|------|------|------|
| new_package_name | ✅ | 新的包名 | `com.newcompany.newapp` |
| keystore_file | ✅ | 签名文件名 | `myapp.keystore` |
| wx_appid | ❌ | 微信AppID（可选） | `wx1234567890abcdef` |

## 🔧 修改内容

工具会自动修改以下文件：

### 1. Android配置文件
- `app/build.gradle` - 更新namespace
- `app/AndroidManifest.xml` - 更新package和Activity引用
- `gradle.properties` - 更新签名配置

### 2. Java源代码
- 创建新的包目录结构
- 移动并更新Java文件中的package声明
- 更新Activity引用

### 3. 可选更新
- 微信AppID（如果提供）

## 📁 备份机制

- 自动创建带时间戳的备份目录
- 备份所有被修改的文件
- 支持一键还原到上次备份

## ⚠️ 注意事项

1. **包名格式**：必须符合Android包名规范
   - 小写字母开头
   - 只能包含字母、数字、下划线和点号
   - 至少包含一个点号

2. **签名文件**：必须存在于signTool目录中

3. **微信AppID格式**：`wx` + 16位十六进制字符

4. **备份重要**：修改前会自动备份，但建议手动备份重要文件

## 🔄 完整工作流程示例

### 步骤1：生成新签名
```bash
cd signTool
./generate_keystore.sh mynewapp
# 生成：mynewapp.keystore，密码：mynewapp123456
```

### 步骤2：获取MD5签名值
```bash
./get_md5_signature.sh mynewapp.keystore mynewapp
# 获取MD5值用于微信开放平台
```

### 步骤3：修改包名
```bash
./change_package.sh com.mynewcompany.mynewapp mynewapp.keystore wx1234567890abcdef
```

### 步骤4：清理并重新构建
```bash
cd ../build/jsb-link/frameworks/runtime-src/proj.android-studio
./gradlew clean
./gradlew assembleRelease
```

### 步骤5：如需还原
```bash
cd ../../../../signTool
./change_package.sh restore
```

## 🐛 常见问题

### Q: 包名格式错误怎么办？
A: 确保包名符合规范：小写字母开头，包含点号，如 `com.company.app`

### Q: 签名文件找不到？
A: 确保签名文件在signTool目录中，文件名正确

### Q: 如何查看当前包名？
A: 查看 `build/jsb-link/frameworks/runtime-src/proj.android-studio/app/build.gradle` 中的namespace

### Q: 还原后还需要重新构建吗？
A: 是的，还原后需要清理构建缓存并重新构建

### Q: 为什么src目录中少了com文件夹？
A: 这是正常的，包名修改工具会：
1. 复制WXEntryActivity.java到新的包目录
2. 询问是否删除旧的com目录
3. 如果选择删除，旧的com目录会被移除
4. 可以通过还原功能恢复原始结构

### Q: 如果误删了文件怎么办？
A: 使用还原功能：`./change_package.sh restore`，或者从备份目录手动恢复

## 📞 技术支持
